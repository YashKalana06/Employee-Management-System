# Employee Management System in C++

A console-based Employee Management System developed using C++ and Object-Oriented Programming (OOP) concepts.

## Project Overview

This project helps manage employee records through a simple, menu-driven interface. Users can add, view, search, update, and delete employee information.

## Features

- Add employee records
- Display all employees
- Search employees by ID
- Update employee details
- Delete employee records
- Calculate monthly and annual salary
- Store and retrieve records using file handling
- Prevent duplicate employee IDs

## Technologies Used

- C++
- Object-Oriented Programming
- Standard Template Library (STL)
- Vector
- File Handling
- Visual Studio Code

## OOP Concepts Used

- **Classes and Objects:** Represent people, employees, and the management system.
- **Encapsulation:** Keeps employee department and salary private.
- **Inheritance:** The Employee class inherits from Person.
- **Polymorphism:** Uses virtual functions and function overriding.
- **Constructors:** Initialize objects when created.

## How to Run

1. Install a C++ compiler such as GCC.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Compile the program:

   `g++ -std=c++17 main.cpp -o employee.exe`

5. Run on Windows PowerShell:

   `.\employee.exe`

## Data Storage

Employee records are stored in `employees.txt`, which is created automatically when records are saved. Keep this file in the program's working directory.

This project was created for academic learning and to demonstrate C++ programming and OOP concepts.
